Status: v1 — hub del ecosistema construido y estándar de marca Nexo aplicado (tokens violeta claro/oscuro, chrome compartido con app-switcher, `/help` e i18n es/en/pt). Este repo es la **referencia viva** del estándar de marca que las demás herramientas copian.
